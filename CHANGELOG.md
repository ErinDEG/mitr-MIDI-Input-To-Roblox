# Changelog

## 1.6 — 2026-10-17

First public GitHub release.

- Native macOS MIDI-to-keyboard bridge for the 61-note Virtual Piano layout.
- MIDI file import, automatic octave fitting, and optional Humanize timing.
- Synchronized falling-note visualizer, seek bar, scroll seeking, and floating full-screen overlay.
- Optional resume countdown and speed controls in 10-point steps from 10–300%.
- Persistent light/dark theme preference.
- Complete source, local build script, 147 built-in checks, documentation, and original demo MIDI files.
